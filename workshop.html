رأی ۲: B ≻ C ≻ A
رأی ۳: C ≻ A ≻ B

🔄 چرخه تشکیل شد! هیچ برنده‌ای وجود ندارد

💡 چرا این مهم است؟
A ≻ B یعنی A از B بهتر است · B ≻ C یعنی B از C بهتر است · C ≻ A یعنی C از A بهتر!
مثل اینکه بگوییم «علی از رضا بالاتر، رضا از سارا بالاتر، سارا از علی بالاتر» — یک چرخه بی‌پایان!

پس روش مقایسه دو به دو همیشه جواب نمی‌دهد. سؤال مهم: پس چه ویژگی‌هایی باید از یک سیستم رأی‌گیری خوب انتظار داشته باشیم؟
